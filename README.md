# CYBERPLAY - 10+ 2-Player P2P Arcade Hub

A futuristic, cyber-themed multiplayer arcade website featuring 10+ real-time two-player games.

## 🚀 Key Features
- **Zero Server Overhead:** Powered entirely by WebRTC via **PeerJS**. No Node.js backend required!
- **Instant Room Code System:** Player 1 shares their short Room ID with Player 2 to sync instantly.
- **10+ Multiplayer Games Included:**
  1. Tic-Tac-Toe Neon
  2. Connect Four
  3. Rock Paper Scissors Deathmatch
  4. Speed Tapper Rush
  5. Cyber Pong (Synchronized Canvas)
  6. Lightning Reflex Test
  7. Nim 21 Coins Strategy
  8. Memory Grid Clash
  9. Laser Air Hockey
  10. Dots & Squares
  11. Buzzer Trivia Duel
  12. Cyber Hangman
- **Responsive & Cyberpunk Glassmorphic UI:** Smooth neon animations, dark mode aesthetic, and mobile support.

## 📦 How to deploy on GitHub Pages (100% Free):
1. Create a new repository on [GitHub](https://github.com/new).
2. Upload all files (`index.html`, `style.css`, `app.js`, `README.md`) directly to your repository repository root.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` (or `master`) and `/root`, then click **Save**.
5. Your arcade website will be live at `https://<your-username>.github.io/<repo-name>/`!
